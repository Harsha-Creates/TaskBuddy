# TaskBuddy
It is used to manage Tasks

Features:
Task Management — Add tasks with custom priority (High, Medium, Low) and categories (General, Personal, Student, Work).
Progress Bar — Real-time visual tracker displaying completed vs total tasks.
Dark & Light Mode — Instant theme switcher with smooth color transitions.
Auto-Save — Persists tasks to `localStorage` so data stays after reloading.
One-Click Actions — Mark as complete/undo, delete tasks, or clear all at once.
Responsive & Clean UI — Centered card layout optimized for mobile and desktop.
